# Attachment uploads and size constraints

Locally authored demo manual for the fictional RelayDesk service. Not a public vendor specification.

## Attachments

The attachment endpoint accepts PDF, PNG and plain text files up to 10 MiB. A 413 means the request body exceeds the size limit; a 415 means its media type is unsupported. Multipart requests need a boundary generated by the HTTP client.

## Troubleshooting

Check file size before uploading when the server returns 413. Compress or split large attachments below 10 MiB. For 415 verify the file type and multipart Content-Type. Let the HTTP library generate the multipart boundary instead of setting a bare multipart/form-data header. Executable attachments are not supported.
